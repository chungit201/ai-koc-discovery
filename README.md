# DETOLA — AI KOC Discovery

Hệ thống AI tìm và đề xuất KOC TikTok phù hợp cho chiến dịch (dữ liệu từ Kalodata), tối ưu chi phí token, scale 50–500 KOC, có khả năng resume khi bị gián đoạn.

- Tổng quan dự án: [docs/00-problem-statement.md](docs/00-problem-statement.md)
- Plan triển khai: [docs/01-plan.md](docs/01-plan.md)
- Mô hình MVP & kiến trúc: [docs/02-architecture.md](docs/02-architecture.md)

## Chạy local

```bash
npm install
npm run dev   # http://localhost:3000
```

Cấu hình bí mật (Kalodata, LLM API key) đặt trong `.env.local` — không commit.

## Trạng thái

Đang ở Step 0 (khởi tạo). Giới hạn hiện tại và hướng mở rộng sẽ được cập nhật khi hoàn thành các step.
