# DETOLA — AI KOC Discovery

Tìm, chấm điểm và đề xuất KOC TikTok (mỹ phẩm, VN) từ dữ liệu Kalodata, kèm trợ lý AI **Tola** trả lời
bằng dữ liệu thật và dẫn chứng.

1. [Khởi động dự án](docs/01-getting-started.md)
2. [Tola AI — cách vận hành](docs/02-tola-ai.md)
3. [Dữ liệu trong MongoDB](docs/03-database.md)
4. [Crawl dữ liệu Kalodata](docs/04-crawl.md)

```bash
npm install
npm run db:tunnel   # terminal riêng
npm run dev         # http://localhost:3000
```
