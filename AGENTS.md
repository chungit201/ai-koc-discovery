## Project context

AI KOC Discovery for DETOLA. Read `docs/00-problem-statement.md` (project overview & requirements) and `docs/01-plan.md` (step-by-step plan) before working. Work proceeds one step at a time with the user; update checkboxes in the plan when a step is done.

### ⚠ IMPORTANT — Kalodata Open API is OFF (user decision 2026-11-01)
Do not use the API key. `KalodataClient` throws unless `KALODATA_API_ENABLED=1`; never set that flag yourself. All data comes from the Kalodata web session (`npm run crawl:web`).

### ⚠ IMPORTANT — paid usage needs explicit approval
Never run anything that spends **Kalodata Open API credits** (every `/openapi/v1/...` endpoint except the free `credit/balance` and `credit/logs`) without asking the user first and receiving an explicit yes. The request must state: endpoints, number of calls, estimated credits, and current balance. Mentioning the cost and proceeding is not enough. Scripts that spend credits: `npm run crawl`, `npm run avatars`, `npm run probe`.

### Anti-hallucination rules (mandatory, see `docs/04-data-model.md` §3.1)
- All numbers are computed by code from the DB, never generated by the LLM.
- LLM-written reasons may only cite existing `evidence_id`s; the validator drops any reason with missing/invalid evidence.
- Audience age/gender and cost are always labeled "ước tính" (estimate) with `confidence` and `basis` evidence ids.
